### Advent of Code 2015

This is my many-years-late attempt at [Advent of Code 2015](https://adventofcode.com/2015/); I'm posting it publicly online as a way to pressure myself to do a decent job.

I'll mostly be using Python for simplicity, but might have to switch later if performance is significant - these are (as of the beginning) running on a vintage 2013 Thinkpad, so not a huge amount of surplus cycles. No promises are made about readability or commenting but I will give an honest effort to make it legible. 

### Retrospective 

Having now finished this, my thoughts:
* I'm really glad I did this, and think it's been a nice chance to flex my code muscles
* It's clear that my understanding of Python has some significant gaps - I've heard good things about 'Fluent Python' and think I might spend some time doing background reading before I do the next year's challenges.
* Day 19 Part 2 was simply not what I expected, and I should look more closely at the input data for any similar challenges
* I think I will take a break to read some books and then start with AoC 2016, still in Python. There's clearly a lot I have to learn and I would rather improve on that than switch to e.g. Rust and have an equally rough idea of the language's advanced features.
