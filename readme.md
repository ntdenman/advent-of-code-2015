### Advent of Code 2015

This is my many-years-late attempt at [Advent of Code 2015](https://adventofcode.com/2015/); I'm posting it publicly online as a way to pressure myself to do a decent job.

I'll mostly be using Python for simplicity, but might have to switch later if performance is significant - these are (as of the beginning) running on a vintage 2013 Thinkpad, so not a huge amount of surplus cycles. No promises are made about readability or commenting but I will give an honest effort to make it legible.
